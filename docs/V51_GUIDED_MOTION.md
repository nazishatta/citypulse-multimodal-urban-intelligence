# CityPulse v5.1 — Guided motion

Three added visual scenes: selected terms reveal, synchronized posted-review and mean-rating trends, and actual DBSCAN label reveal. Scenes render with their own Play/Pause/Replay/Final controls. System reduced-motion disables the scene. All numerical values originate from the current selected population, and all demo records retain the existing synthetic disclosure. Clustering maps display actual fit labels, never staged reassignment. The spatial reveal is a coordinate canvas, not a street basemap.

## Limitations

Auto-start is a browser-side behavior and requires a manual Chrome acceptance run. Embedded visual controls are independent of native Plotly selection cross-filtering. No photos or additional Yelp records are supplied. The scene is re-created when the Streamlit tab becomes active; no continuous timer runs in Python.
